# Reference catalog

Start with the [reviewed source inventory](REFERENCE_INVENTORY.md). The [machine-readable catalog](references.json) contains public source URLs, provenance, dates and limitations. Checked October 17, 2026.

This catalog links sources; it does not redistribute the photographs, PDFs or CAD files. A public source is not automatically licensed for reproduction. Keep unknown geometry provisional and distinguish upload dates from capture dates.

Use the [reference-gap issue template](../.github/ISSUE_TEMPLATE/reference_gap.md) for missing or conflicting evidence. Record the intended building, the exact feature supported, the source's date/license, and any limitation. Verify foreground/background identity visually rather than relying on names or alt text.

Important unresolved items include the amphitheater's current row count (historical 22 tiers versus current 30 rows/steps), Kasser plan-to-campus registration, and unmeasured Cole cupola dimensions.
